# Квартирник: бот объявлений об аренде (Бишкек)

Объявление стоит **10 сом**. Человек заполняет анкету в боте, платит через Finik (QR / банковское приложение, как на diamond.kg), и объявление сразу появляется в группе.

**Меню бота:** Сдать квартиру · Найти квартиру · Смотреть объявления · Мой профиль · Перейти в группу.

**Поля объявления:** фото (одно, обязательно), город, район, тип (комнаты, этаж), цена (для «Ищу» это бюджет), пол, количество человек, комментарий, контакты, актуально или нет.

В «Мой профиль» можно снять объявление с актуальных (в группе появится «❌ Неактуально»), вернуть обратно или удалить.

## Запуск

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → получите токен.
2. **Группа.** Создайте группу, добавьте бота и сделайте его администратором (право писать, редактировать и удалять сообщения). Узнайте id группы (вида `-100…`): напишите в группе любое сообщение, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100…}`. Ссылку-приглашение возьмите в настройках группы.
3. **База.** В Cloudflare: Storage & Databases → D1 → Create database `kvartirnik-db`. Скопируйте её id в `wrangler.toml` (`database_id`). Таблицы создадутся сами.
4. **Finik.** Нужны те же четыре значения, что на diamond.kg: `FINIK_API_KEY`, `FINIK_PRIVATE_KEY`, `FINIK_PUBLIC_KEY`, `FINIK_ACCOUNT_ID`. Имя QR в приложении банка по умолчанию `kvartirnik` (можно поменять секретом `FINIK_QR_NAME`).
5. **Деплой.** Загрузите папку в GitHub-репозиторий и подключите к Cloudflare Workers (Workers & Pages → Create → Import a repository), или выполните `npm install && npx wrangler deploy`.
6. **Секреты** (Worker → Settings → Variables and Secrets, тип Secret): `BOT_TOKEN`, `WEBHOOK_SECRET` (любая длинная случайная строка), `GROUP_ID`, `FINIK_*`. Необязательно: `ADMIN_ID` (ваш Telegram id, туда придут сообщения о проблемах с оплатой).
7. **Переменные** в `wrangler.toml`: `BOT_USERNAME`, `GROUP_LINK`, при публичной группе `GROUP_USERNAME`.
8. **Включение.** Один раз откройте в браузере `https://<адрес-воркера>/setup?key=<WEBHOOK_SECRET>`. Ответ покажет, подключён ли вебхук, виден ли Finik и состоит ли бот в группе.
9. **В кабинете Finik** укажите адрес вебхука `https://<адрес-воркера>/api/finik/webhook`, если он задаётся там отдельно (в запросе на оплату бот уже передаёт его сам).

## Как это работает

- Анкета хранится в D1, шаги: фото (обязательно, одно) → город → район → тип → цена → пол → количество человек → комментарий → контакты → предпросмотр.
- «Оплатить» создаёт платёж в Finik (`PaymentId` = номер объявления), ссылка живёт 30 минут.
- Finik присылает подписанный вебхук, бот проверяет подпись (RSA-SHA256), сумму (не меньше 10 сом) и публикует объявление. Повторный вебхук игнорируется.
- Если оплата прошла, а публикация не удалась (например, бот не админ), объявление остаётся оплаченным, а вам (`ADMIN_ID`) приходит предупреждение.
- Неоплаченные черновики помечаются просроченными раз в 10 минут.

## Проверка

`node test/smoke.mjs` прогоняет весь путь на моках: анкета, оплата, вебхук с подписью, публикация, актуальность, удаление, защита от чужих действий.
